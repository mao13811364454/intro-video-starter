# 项目简报

名称和 ID 见 `project.json`。先确认以下内容，再填写技术参数和脚本。

- 介绍对象、受众、主要目的：待确认
- 播放场景、片长、画幅、风格：待确认
- 素材来源、使用与公开范围：待确认
- 主持人、人声、音乐安排：待确认
- 已确认决定：暂无
- 暂定理解与待决问题：暂无

素材登记在 `assets.json`，逐镜脚本在 `script.md`。原件放 `assets/source/`，处理后的文件放 `assets/derived/`。此目录默认被 Git 忽略；发布自己的项目之前单独检查文件和授权。

按仓库 `docs/WORKFLOW.md` 推进，先确认脚本与样片，再扩展全片。保留实际命令、版本和检查结果；首次成片及重大修改需观看并试听全片，已验收版本的细小调整按该流程限定范围和验证。
