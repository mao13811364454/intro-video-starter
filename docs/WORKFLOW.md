# 从素材到介绍视频

| 阶段 | 产物 | 进入下一阶段的依据 |
|---|---|---|
| 明确目标 | 项目简报：对象、受众、目的、播放场景、片长与画幅 | 使用者确认；未定项明确标注 |
| 盘点素材 | 素材账：身份、尺寸、时长、可用区间、主要内容、限制和授权 | 实际查看和听取素材；说明与事实来源分开 |
| 主持词与脚本 | 稳定段落 ID、讲述、素材源入出点、动效用途、声音与字幕 | 使用者审核后录制；可按段录制 |
| 实录对齐 | 以实际讲述校对文字、专名和源时码 | 人工复听；自动转写只能作草稿 |
| 短样片 | 覆盖主要版式、画中画、观察停顿、音乐和字幕 | 使用者确认观看效果 |
| 全片 | 全片工程、新文件名 MP4、自动检查与人工审看记录 | 完整观看并试听，核对内容、字幕、同步、切换和导出要求 |

动效围绕内容安排。示例中的 18 秒、4 秒观察、标题字数和场景数量仅用于演示；不自动成为新项目规则。依据观众阅读和观察需要调整，不堆叠无信息作用的标签。

收到“修改 P03 的第二个镜头”时，先更新受影响脚本和素材映射，再修改工程。局部样片通过后，全片仍须重新确认拼接和声音连续性。保留原素材、使用的版本、渲染命令、成片和检查报告。

这些脚本不自动核实科普事实、匹配所有素材或检查口型。尚无主持人、旁白或准确时码时，不能以等分字幕时间冒充实际音画同步。

公开分享只处理经过确认的内容清单。新项目默认在被忽略的 `projects/` 下；发布时重新核对素材许可、第三方声明和实际 Git 提交，检查截图、日志和文件元数据中是否含私人内容。
